# Locale: en-US

## Name
AscendKit

## Subtitle
ASO & Metadata for Indie Devs

## Description
MANAGE YOUR APP STORE LISTING LIKE A PRO

AscendKit is the native macOS tool built for indie iOS developers who take their App AscendKite presence seriously. Sync your metadata, track every change over time, research winning keywords, and design localized screenshots — without sharing your credentials with any third-party server.

YOUR METADATA, VERSION-CONTROLLED
Every sync saves a timestamped snapshot of your App AscendKite Connect listing. Compare any two versions side by side to see exactly what changed — names, descriptions, keywords, promotional text, and localizations. Think of it as git for your app listing.

KEYWORD RESEARCH THAT ACTUALLY WORKS
Powered by Apple's own Search Ads API, AscendKit fetches real popularity scores for any keyword across any market. Build your keyword list, score each term against difficulty, and track ranking trends over time — all from a single dashboard.

SCREENSHOT CREATION BUILT IN
Design localized screenshot templates directly in AscendKit. Layer device frames, custom backgrounds, and text overlays, then export production-ready images for every display size. Translate all screenshot copy in a single Markdown file and re-import in seconds.

COMPETITOR INTELLIGENCE
Look up any competitor's current App AscendKite metadata using the iTunes Lookup API. Compare their keyword strategy, read their descriptions side by side with yours, and discover the gaps your listing can fill.

PRIVACY BY DESIGN
Your API keys and credentials never leave your Mac. AscendKit communicates directly with Apple's official APIs — no relay server, no third-party cloud, no subscription required.

KEY FEATURES
• App AscendKite Connect metadata editor with full localization support
• Snapshot versioning — compare any two versions with a field-level diff
• Keyword research with Apple Search Ads popularity scores and custom difficulty rating
• Keyword ranking tracker with historical trend charts
• Built-in screenshot template editor with text overlays and device frames
• Batch screenshot export for all display sizes
• Competitor keyword and metadata comparison via iTunes Lookup
• Import and export metadata and screenshot copy as Markdown
• Keychain-secured API credentials — never stored in the cloud
